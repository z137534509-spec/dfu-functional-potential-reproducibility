# v1.0.0 - frozen reproducibility release

This initial public release preserves the locked Python analysis script and the nonidentifying derived outputs underlying the secondary analysis of PRJNA506988 longitudinal diabetic foot-ulcer shotgun functional profiles.

## Included

- The fixed-seed analysis script used for the final reported estimand and inference.
- Matched-distance tables, full-recomputation cluster-bootstrap distributions, visit-preserving randomization distributions, comparator-pool audits, sensitivity outputs, and formal result summaries.
- The four figures used in the current manuscript.
- Pinned Python requirements, source-data provenance, citation metadata, and Zenodo metadata.

## Not included

The original `SEED.sub1.map.csv` and `metamap.csv` files are not redistributed. They remain available from BioProject PRJNA506988 and the original study materials. No raw reads, direct identifiers, clinical free text, manuscript submission files, or local paths are included.

## Interpretation boundary

The archived record supports a patient-specific structural observation for broad DNA-level microbial functional potential in one public cohort. It does not establish functional activity, biological mechanism, healing relevance, treatment effects, clinical utility, or external validity.
