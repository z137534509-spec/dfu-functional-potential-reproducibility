# Source-data provenance

This release deliberately excludes the original author-supplied source files. It contains only the locked analysis code and nonidentifying outputs derived from those files.

To reproduce the analysis, obtain the public supplementary source data associated with BioProject PRJNA506988 and the Kalan et al. 2019 study, then place the following two files in one local directory:

```text
SEED.sub1.map.csv
metamap.csv
```

The analysis uses `SEED.sub1.map.csv` for relative abundances assigned to SEED Level-1 categories and `metamap.csv` for the study-supplied patient identifier, visit ordinal, wound-depth, and antibiotic fields. Source data retain their original provenance and terms; they are not relicensed by this repository.

No direct identifiers, contact information, clinical free text, raw reads, or original source tables are included in this release.
