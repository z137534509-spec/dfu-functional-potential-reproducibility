# Reproducibility package: patient-specific microbial functional potential in longitudinal diabetic foot ulcers

This repository preserves the analysis code and nonidentifying derived outputs for the secondary analysis entitled *Patient-specific structure of broad shotgun-derived microbial functional potential in longitudinal diabetic foot ulcers*.

## Scope

The study reanalyzed author-supplied, longitudinal shotgun-metagenomic functional profiles from BioProject PRJNA506988. The primary estimand is the patient-level median of the stage-matched between-patient minus within-patient Bray-Curtis distance across broad SEED Level-1 functional-potential profiles. A positive value indicates that profiles from the same patient were closer than profiles from other patients sampled at the same or adjacent visit ordinal.

This package supports a bounded ecological observation in the source cohort. It does not establish functional activity, mechanism, healing relevance, treatment effects, clinical utility, or external validity.

## Contents

- `code/03_run_functional_stability_full_analysis.py`: locked analysis script.
- `derived/`: nonidentifying sample- and patient-level derived tables, bootstrap distributions, and randomization null distributions.
- `results/`: analysis summaries and comparator-pool, sensitivity, and robustness outputs.
- `figures/`: the four figures used in the current manuscript, generated by the locked analysis.
- `data/README.md`: source-data provenance and input-file requirements. Original source data are not redistributed here.
- `requirements.txt`: Python package versions used for the final analysis.

## Primary result preserved in this release

Among 44 patients with repeated profiles, the median matched between-minus-within Bray-Curtis distance was 0.01535 (95% full-recomputation patient-cluster-bootstrap confidence interval, 0.00757 to 0.02828); 36 of 44 patient-level contrasts were positive. A 9,999-replicate visit-preserving patient-label randomization test gave P=0.0001.

## Reproduction

1. Create a Python 3.12 environment and install the packages in `requirements.txt`.
2. Obtain the two author-supplied source files described in `data/README.md` from the original public study materials.
3. Run:

```text
python code/03_run_functional_stability_full_analysis.py <source_data_dir> <output_root>
```

The source-data directory must contain `SEED.sub1.map.csv` and `metamap.csv`. The supplied script uses a fixed random seed (`20260909`) and writes derived tables, results, and figures beneath the specified output root.

## Data provenance
